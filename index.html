Reflection Rewards Tracker

Tallies dividend tokens actually received by your Solana wallets (StonkFun reward-mode coins, etc.) over any period, so you can check them against thestonkboard.com estimates. Everything runs in this browser tab; nothing is uploaded anywhere except the API queries you configure.

1. Data source

Sent only to pro-api.solscan.io as the token header. Stored in this browser's localStorage. Solscan's free key tier does not include the transfer endpoint this needs; if you see "upgrade your api key level", use the RPC provider instead.
Get a free key at dashboard.helius.dev and paste the mainnet RPC URL it shows. Leaving this blank uses the public mainnet-beta endpoint, which is slow and rate-limited.
Reflection payouts are pushed to you by a distributor. Anything that ran through a DEX, aggregator, limit-order or DCA program, or where your wallet paid out a token or signed, is a trade, not a dividend. You can also ignore a token or a sender from its card below.
